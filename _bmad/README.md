# BMAD Framework Configuration (Gemini Antigravity Edition)

Dette området inneholder kjernemodulene og konfigurasjonsfilene for **BMAD-metodologien** (Breakthrough Method for Agile AI-driven Development), fullt integrert med **Gemini Antigravity** og agent-skills i `.agents/skills/`.

## Moduler:
* **`_config/`**: Manifest- og indekseringsfiler for ferdigheter og prosjektartefakter.
* **`bmm/`**: Business & Market Module (Forretningsanalyse, PRD, verdimodellering).
* **`cis/`**: Creative & Innovation Suite (Brainstorming, historiefortelling, design thinking).
* **`core/`**: Arkitektur, kjerneflyt, kodebygging og kvalitetssikring.
* **`custom/`**: Tilpassede regler og scripts for G56-guimaraes.
