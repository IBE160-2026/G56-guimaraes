# 03 UX Design Phase (Design & Frontend)

Her lagres alt av visuelt design, brukeropplevelse, og frontend-implementasjonsspesifikasjoner for applikasjonen og genererte dokumenter.

## Roller tilknyttet denne fasen

### Kjerneteam
* **UX Designer:** Eier brukeropplevelsen. Tegner UI-skisser og wireframes for det enkle Streamlit-dashboardet.

### Spesialiserte Utviklere (Topp 10 % Personas)
* **Streamlit / SPA Architecture Master (Elite Frontend):** Bygger grensesnittet. Bruker `@st.fragment`, usynlig "State Machine"-mønster i `st.session_state` og asynkrone callbacks slik at appen føles som en lynrask Single Page Application uten reloading-blinking.
* **Typographic & PDF Engine Developer:** Har eksklusivt fokus på "Styrepakken" som skal eksporteres. Skriver piksel-perfekte design-regler for utskrift (CSS Paged Media, WeasyPrint, ReportLab). Kontrollerer sidebrytninger for tabeller og leverer vektoriserte SVG-grafer slik at PDF-en ser profesjonell ut.

**Eksempler på innhold i denne mappen:**
- Wireframes og UI-skisser
- Brukerreiser (User Journeys)
- Designsystem, CSS og PDF-styling-regler
