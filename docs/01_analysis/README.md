# 01 Analysis Phase (Business & Finance)

Her lagres alle artefakter knyttet til forretningsanalysen, regnskapsregler, og finansiell strategi.

## Roller tilknyttet denne fasen

### Kjerneteam
* **Business Analyst (Analytiker):** Eier forretningsverdien og sørger for at systemet faktisk løser problemet med tørre, silo-baserte rapporter. Utarbeider *Product Brief*.

### Domenespesifikke Fageksperter (Topp 10 %)
Siden applikasjonen opererer i finansdomenet, trekkes disse ekspertene inn (eller promptes som agenter) ved behov:
* **GRS-Spesialist:** Ekspert på God Regnskapsskikk (NGAAP) og regnskapsloven. Sikrer at SAF-T parsing følger norske regler.
* **IFRS-Spesialist:** Håndterer kompleksiteten ved flervaluta-konsolideringer og internasjonale krav for SMB-datterselskaper.
* **Strategisk Regnskapsfører (Strategic Advisor):** Analyserer *hvorfor* tallene er som de er. Gir ledelsen råd om hvordan regnskapsmessige tilpasninger påvirker likviditet og skatt på sikt (Continuous AI CFO).

### AI-Orkestreringsroller (Sub-teams)
* **Analyseteam-Orkestrator (Team Lead):** Tar imot rådata, bryter ned behov, og ruter oppgaver til `finansiell-analytiker` (som gjør tallknusing) og `compliance-kontrollør` (som godkjenner).

**Eksempler på innhold i denne mappen:**
- Product Brief (f.eks. proposal.md)
- Markeds- og konkurrentanalyse
- Problem- og målgruppebeskrivelser
- Definisjoner av regnskapsprinsipper og avstemmingsregler
