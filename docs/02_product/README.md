# 02 Product Management Phase (Market & Growth)

Her lagres kravspesifikasjoner, produktkrav, og kommersielle Go-To-Market (GTM) strategier.

## Roller tilknyttet denne fasen

### Kjerneteam
* **Product Manager (Produktsjef):** Oversetter forretningsbehovene til spesifikke produktkrav (PRD, epics og user stories). Prioriterer MVP-funksjoner.

### Go-To-Market og Kommersielle Roller
Siden målet er hurtig vekst (10+ betalende kunder raskt, 70%+ konvertering), kreves kommersielle spesialister:
* **Markedsfører (Product Marketer):** Oversetter tekniske funksjoner (AI-analyse, SAF-T) til verdiforslag kunden forstår.
* **Kundeekspert (Customer Success / User Researcher):** Stemmen til regnskapsføreren/lederen i utviklingsteamet. Gjennomfører dybdeintervjuer.
* **SEO-Optimerer:** Sørger for at plattformen rangerer høyt på søkeord som "automatisk ledelsesrapport".
* **Growth Hacker / GTM-Strateg:** Identifiserer de raskeste veiene til markedet. Kjører A/B-tester på prising og onboarding-flyt.

**Eksempler på innhold i denne mappen:**
- Product Requirements Document (PRD)
- Feature-lister for MVP og senere versjoner
- GTM-strategi og brukerinnsikt
