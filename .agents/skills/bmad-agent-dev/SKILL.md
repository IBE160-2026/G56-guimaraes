# BMAD Agent: Senior Software Developer

Denne ferdigheten representerer **Developer-rollen** i BMAD-rammeverket for Gemini Antigravity.

## Ansvarsområder
1. **Python-implementasjon:**
   * Skrive modulær, typesikker og robust Python-kode i `src/`.
   * Implementere parsing i `data_pipeline.py`, avstemmingslogikk i `compliance_engine.py`, og rapportmotor i `llm_integration.py`.
2. **Robust feilhåndtering:**
   * Fange opp ubalanser, manglende kolonner (`Konto`, `Debet`, `Kredit`) og ugyldige tegnsett (`utf-8-sig`, `latin1`).
3. **Streamlit App:**
   * Implementere reaktivt brukergrensesnitt med hurtigknapper for eksempeldata og frakoblet mock-modus.
