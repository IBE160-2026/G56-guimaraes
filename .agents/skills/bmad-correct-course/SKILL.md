# BMAD Skill: Course Correction (Kurskorrigering)

Instruksjoner for å håndtere endringer i prosjektplan og arkitektur.

## Prosedyre
1. Evaluer avviket mot eksisterende PRD og arkitekturbeskrivelse.
2. Dokumenter avviket og begrunnelsen i `docs/01_analysis/AVVIK_FRA_PROPOSAL.md`.
3. Oppdater relevante tester og moduler.
4. Oppdater prosjektplanen og memlog.
