# BMAD Skill: Create Epics & Stories

Instruksjoner for dekomponering av krav til agile arbeidspakker.

## Mal for User Story
```markdown
### Story X.Y: [Kort tittel]
* **Som en:** [Rolle, f.eks. Daglig leder / Sensor]
* **Ønsker jeg:** [Funksjonalitet]
* **Slik at:** [Forretningsverdi]
* **Akseptansekriterier:**
  1. [Testbart kriterium]
```
